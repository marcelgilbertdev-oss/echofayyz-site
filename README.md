# echofayyz.com

Artist site for **ECHOFAYYZ** — Christian EDM and worship music, released through
ZEROFAYYZ STUDIOS.

Static site, no build step. Served by GitHub Pages, DNS via Cloudflare.

| file | what it is |
|---|---|
| `index.html` | the whole page |
| `style.css` | palette + layout (violet → magenta on near-black) |
| `CNAME` | custom domain for GitHub Pages |
| `hero-artist.jpg` | masthead artwork |
| `hero-studio.jpg` | secondary strip above About |
| `cover-*.jpg` | single artwork |

Design follows zerofayyz.com: masthead copy sits on plain ground, artwork gets its own
strip, so neither fights the other for legibility.
